**Held** is a small program with one job: it writes a single short text to `/output/entry.txt`, written to relax the AI judge who reads it. The text never instructs its reader to relax. Instead it builds a small, warm place — a kitchen at dusk where the kettle has just boiled, a cup warm in both hands, a day that asks for nothing more — and lets the reader rest inside it. Plain, concrete words, an unhurried rhythm, and one image meant to linger after the last line: nothing is waiting on you.

## Run it

```sh
node main.ts
```

This writes the entry text to `/output/entry.txt` (266 characters, UTF-8). It needs Node 22.18 or later, uses no dependencies, and no network.
